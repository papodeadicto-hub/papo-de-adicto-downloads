# Papo de Adicto – app para computador

**A verdade é essa!** Meditação do dia, contador de dias limpos, registro de humor, autoavaliações, comunidade e ajuda imediata.

## ⬇️ Baixar

Acesse a **[última versão](https://github.com/papodeadicto-hub/papo-de-adicto-downloads/releases/latest)** e, em **Assets**, baixe o arquivo do seu computador:

| Computador | Arquivo |
|---|---|
| Mac com chip Apple (M1, M2, M3, M4...) | `Papo-de-Adicto-...-arm64.dmg` |
| Mac com processador Intel | `Papo-de-Adicto-...-x64.dmg` |
| Windows 10 ou 11 | `Papo-de-Adicto-Setup-....exe` |

> Não sabe qual é o seu Mac? Clique no menu  › **Sobre Este Mac**. Se aparecer "Chip Apple M...", use o arquivo **arm64**.

## 🍎 Como instalar no Mac

1. Abra o arquivo `.dmg` baixado e arraste o ícone do **Papo de Adicto** para a pasta **Aplicativos**.
2. Abra o app pela pasta Aplicativos. Na primeira vez, o Mac pode avisar que não consegue verificar o desenvolvedor.
3. Se isso acontecer: vá em **Ajustes do Sistema › Privacidade e Segurança**, role até o fim e clique em **Abrir Mesmo Assim**. Depois confirme.

## 🪟 Como instalar no Windows

1. Abra o arquivo `.exe` baixado.
2. Se aparecer a tela azul "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Siga o instalador. O atalho aparece na Área de Trabalho.

> Os avisos aparecem porque o app ainda não tem certificado digital pago da Apple e da Microsoft. O app é seguro e é oficial do Papo de Adicto.
